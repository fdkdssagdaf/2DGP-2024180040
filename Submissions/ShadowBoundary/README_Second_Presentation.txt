Shadow Boundary second-presentation hand-in files

Files
- Shadow_Boundary_Second_Presentation.pptx: four-slide presentation
- Shadow_Boundary_Second_Presentation_Script.txt: 90-second speech and checklist
- shadow_boundary_demo.py: one-stage prototype of the core game loop
- run_shadow_boundary_demo.bat: Windows launcher

Run
1. Use a Python environment with Pico2D installed.
2. Double-click run_shadow_boundary_demo.bat.
3. Or run this from the repository root:
   python Submissions\ShadowBoundary\shadow_boundary_demo.py

Controls
- Left/Right or A/D: move
- Space or Up: jump
- Z: switch between reality and shadow
- E: push the box
- R: restart
- ESC: quit

The progress slide describes the features implemented in this demo.
It does not claim that all three planned stages are complete.
The first plan specified a development order, not week-by-week dates.

Before submitting through e-class, add the presentation and demo files to
the GitHub project repository. Record and review the gameplay video, upload
it to YouTube, and submit its link along with the repository link.
