그림자 경계 2차 발표 파일 안내

발표자료
- Shadow_Boundary_Game_Description_and_Progress.pptx
  1쪽: 게임 설명
  2쪽: 개발 계획과 현재 진행 상황
- Shadow_Boundary_Second_Presentation.pptx: 발표 표지와 추가 안내를 포함한 버전

게임 데모
- shadow_boundary_demo.py: 한 구간 플레이 데모
- run_shadow_boundary_demo.bat: Windows 실행 파일

실행 방법
프로젝트 저장소 루트에서 실행:
python Submissions\ShadowBoundary\shadow_boundary_demo.py

조작
- 방향키 또는 A/D: 이동
- Space 또는 위쪽 방향키: 점프
- Z: 현실과 그림자 세계 전환
- E: 상자 밀기
- R: 다시 시작
- ESC: 종료

현재 데모는 한 구간입니다. 처음 계획했던 세 구간을 모두 완성했다는 의미는 아닙니다.
1차 기획에는 주차별 날짜가 아니라 개발 단계의 순서가 적혀 있습니다.
